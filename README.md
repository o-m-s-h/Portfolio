# Omkar Portfolio

This build is intentionally self-contained.

The active website is `index.html`, including all its styles and JavaScript.
The `src/` directory contains the earlier React version and is not loaded by this page.

## Features

- Soft white and blue layout with responsive project cards.
- Interactive architecture previews with keyboard-accessible tabs.
- AI and systems project filters and expandable case studies.
- Searchable quick navigation (`Ctrl+K` / `Cmd+K`), mobile menu, and copy email.
- Visible keyboard focus, reduced-motion support, and no external asset dependencies.

## Fastest way to open it
Double-click `index.html`. No npm install is required.

## Deploy
Upload the folder to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages).

## Optional local server
```bash
python -m http.server 8000
```
Then open http://localhost:8000.
